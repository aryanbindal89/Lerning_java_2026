## 🏗️ Creating Your Own Java Class

In Java, a **class** is a blueprint used to create objects.

A class can contain:

* 🔹 Variables / Fields
* 🔹 Methods
* 🔹 Constructors
* 🔹 Objects and their behavior

### 💡 Basic Structure

```java
class Student {
    String name;
    int age;

    void displayInfo() {
        System.out.println("Name: " + name);
        System.out.println("Age: " + age);
    }
}
```

An object can then be created from the class:

```java
Student student1 = new Student();

student1.name = "Aryan";
student1.age = 18;

student1.displayInfo();
```
