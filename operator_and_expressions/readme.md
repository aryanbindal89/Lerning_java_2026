# ⚙️ Operators & Expressions in Java

> *"Every great Java program begins with a single operator and a curious mind."* 🚀

This folder contains Java programs that explore the fundamentals of **Operators** and **Expressions**. These concepts are the backbone of programming, helping you perform calculations, compare values, and build logical solutions.

---

## 📂 Contents

| 📄 File | 📖 Description |
|---------|----------------|
| `associative_of_operators.java` | Demonstrates how operator associativity affects the order of evaluation. |
| `types_of_operators.java` | Explains different types of Java operators with practical examples. |
| `incriment_or_decrement.java` | Demonstrates pre-increment, post-increment, pre-decrement, and post-decrement operators. |
| `practice_set_2.java` | Practice problems to strengthen your understanding of operators and expressions. |

---

## 📚 Topics Covered

✨ **This folder covers:**

- ➕ Arithmetic Operators
- 📝 Assignment Operators
- ⚖️ Relational (Comparison) Operators
- 🤝 Logical Operators
- 🔢 Bitwise Operators
- 📈 Increment & Decrement Operators
- 🔗 Operator Associativity
- 🧮 Expressions in Java
- 💡 Practice Problems

## ▶️ How to Run

1. Open the project in **VS Code** (or any Java IDE).
2. Navigate to the desired Java file.
3. Compile the program:

```bash
javac FileName.java
```

4. Run the program:

```bash
java FileName
```

**Example**

```bash
javac associative_of_operators.java
java associative_of_operators
```
