# 📖 About

This folder is a part of my **Java Learning Journey** where I explored one of the most important concepts in programming: **Methods (Functions)** and **Recursion**.

These programs explain how Java methods work, how data is passed between methods, how methods can be overloaded, how variable-length arguments simplify code, and how recursion allows a function to solve problems by calling itself.

---

# 📂 Files Included

| 📄 File | 📌 Description |
|----------|----------------|
| `methods_in_Java.java` | Introduction to methods and creating user-defined methods |
| `method_overloading.java` | Understanding method overloading with multiple examples |
| `variable_Arguments_in_Java.java` | Using variable-length arguments (VarArgs) in Java |
| `recursion_in_java.java` | Basics of recursion with recursive function examples |
