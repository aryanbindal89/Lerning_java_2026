# 📖 About This Folder

This folder contains Java programs that introduce the concept of **Conditional Statements** and **Decision Making**.

You'll learn how Java executes different blocks of code depending on conditions using **if-else**, **switch-case**, and **logical & relational operators**.

Every program is beginner-friendly and written with clean formatting to make learning easier.

---

# 📂 Contents

| 📄 File Name | 📚 Description |
|--------------|----------------|
| **if else statement.java** | Learn how to use `if`, `if-else`, and nested conditions. |
| **relational logical operators.java** | Understand comparison operators and logical operators in Java. |
| **switch case statement.java** | Learn how to use `switch` statements for multiple choices. |
| **practice set 3.java** | Practice problems based on conditional statements and operators. |

# ▶️ How to Run

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/aryanbindal89/Lerning_java_2026.git
```

### 2️⃣ Open the Project

Open the project in **VS Code**, **IntelliJ IDEA**, or any Java IDE.

### 3️⃣ Compile

```bash
javac filename.java
```

Example:

```bash
javac "if else statement.java"
```

### 4️⃣ Run

```bash
java ClassName
```

Example:

```bash
java if_else_statement
```

> **Note:** Replace `ClassName` with the class name inside your Java file.
