# ☕ Variables and Data Types

Welcome to the **Variables and Data Types** section of my **Java Learning** repository! 🚀

This folder contains beginner-friendly Java programs that help build a strong foundation in Java programming.

---

## 📚 Topics Covered

- Variables
- Primitive Data Types
- User Input using `Scanner`
- Literals
- Basic Arithmetic Operations
- Expressions
- Practice Problems

---

## 📂 Programs Included

| Program | Description |
|---------|-------------|
| 🧮 Sum 3 Numbers in Java | Takes three numbers as input and calculates their sum. |
| ⌨️ Input in Java | Demonstrates how to take user input using the `Scanner` class. |

| 💡 Practice Set 1 | A collection of practice questions to strengthen Java fundamentals. |

4. Run the program:

