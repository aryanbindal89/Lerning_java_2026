## 🧠 Key Concepts

### Abstract Class

An abstract class is a class that cannot be directly instantiated and can contain both abstract and concrete methods.

### Abstract Method

An abstract method is declared without a body and must be implemented by its subclass.

### Interface

An interface defines a contract that classes can implement. Java allows a class to implement multiple interfaces.

### Polymorphism

Polymorphism allows the same reference type to refer to objects of different implementations.
